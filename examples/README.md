## What These Examples Demonstrate

- A clear executive summary.
- Ranked opportunity table with scores.
- Evidence-backed opportunity details.
- Market and competitive context where relevant.
- A concrete wedge or recommended angle for each opportunity.
- Method and limitations stated explicitly.
